About

Turning raw data into platforms people can rely on

I'm a hands-on data engineer who enjoys the whole path of data — ingestion, transformation, storage, and consumption — and the unglamorous work that keeps it healthy: monitoring, optimisation, governance and fast issue resolution.

Most of my career has been on the Microsoft stack: SQL Server and SSIS early on, then Azure SQL, Azure Data Factory, Synapse dedicated SQL pools, Databricks and ADLS Gen2, and now Microsoft Fabric. I've led support teams keeping production ETL and warehouses stable, and worked as an individual contributor designing end-to-end solutions.

I also care about data literacy — helping teams write better SQL, review code for performance, and follow shared standards for modelling and naming.
